# Security Policy

## Maintenance Status

cJSON no longer has enough active maintainer capacity to guarantee ongoing
maintenance, see [#1080](https://github.com/DaveGamble/cJSON/issues/1080).
Security reports will still be reviewed when time permits, but there may be
significant delays and no response-time commitment can be made.

Do not rely on this repository as the only path for obtaining timely security
fixes. If your project requires timely security fixes, consider using or
maintaining an actively maintained fork of cJSON.

Pull requests that include a clear description of the problem, a reproducer
or test case, and a proposed fix are especially helpful and much easier to
review.

## Reporting a Vulnerability

If you know of a publicly disclosed security vulnerability for cjson, please IMMEDIATELY contact wp_scut@163.com and peterlee@apache.org to inform the cjson Team.

IMPORTANT: Do not file public issues on GitHub for security vulnerabilities.
